# 習寫簿虛線描寫工具 — 使用說明

## 開啟方式
直接雙擊 `index.html` 用 Chrome / Edge 開啟即可（單機、免安裝）。
建議連網開啟一次（需載入 pdf.js / jsPDF CDN 之後 PDF 匯出才可用）。

## 完整流程（對應你的需求）
1. **上傳**：PDF（多頁自動拆頁）或截圖（PNG/JPG），可一次多檔，左側自動變成分頁。
   **拖拉上傳**：直接把檔案拖進瀏覽器視窗放開即可，全畫面會出現藍色提示。PDF / 圖片會新增為作業內頁分頁，字體檔會直接加入字體庫，兩種混在一起拖也沒關係，工具會自動分流；不支援的檔案會被略過並列出檔名。
2. **自動掃描田字格**：按「自動掃描田字格」，空白田字格會以**黃色亮光**自動選取。
   **一格＝四小方格＋中間十字虛線組成的整個田字格**（虛線是筆劃定位線，只定位、不拆格）；漢字田字格右側的細窄格就是該字的注音格。
   原理是抓格線投影找直橫線，再以密度區分實線格界與虛線定位線，只用實線組格。以下自動處理：
   - 有字範例列：框出但顯示灰色、不預選（需要也可點選加入）
   - 空白練習列：黃色亮光、自動選取
   - 頂部訂正大格、右側淺藍標籤條：排除（標籤條底色不會再拉歪偵測）
   - 黑白印刷的格線也認得。各家版本通用。
   若掃不全 → 按「手動框選補格」拖曳範圍 → 輸入列/欄數與欄型（漢字+右側注音交替 / 純注音 / 純漢字）自動細分。
3. **點選**：點擊格子選取/取消，全選 / 取消全選 / 只選漢字 / 只選注音 / **只選空白**皆有。
   漢字大格 / 右側窄注音格 / 純注音格（小一）依寬高比自動分類，右表可再手動更正。
4. **填字**：右側表格為每個選取格輸入漢字與注音（**直式順序：由右而左、由上而下**，從畫面右邊開始順著編）。
   - 快速：上方輸入漢字串「讓我走細雨」→ 依序填入。
   - 複製：第二列要描第一列 → 選取第二列空格 →「從上一列複製」。
5. **微調預覽**：選完即時出現虛線底稿。注音採直排、按符號數均分格高並撐滿格寬（純注音格已放大）；漢字維持原大小。**漢字大小、注音大小分開調**，另可調 X/Y 偏移、顏色、不透明、粗細、填色/虛線描邊模擬。
6. **字體**（支援 `.ttf` / `.otf` / `.woff` / `.woff2` / **`.ttc`**）：**漢字格、注音格可各選一種字體**（左側兩個下拉選單）。
   - 網站 `fonts/` 資料夾內的 `builtin-hanzi.*`（文鼎標楷虛線國字）、`builtin-zhuyin.*`（文鼎虛線注音）開啟即自動載入為預設，且永遠鎖定在庫內。
   - 「＋上傳自備字體」或**直接拖字體檔進視窗**：檔名含「注音」自動歸注音格，其餘歸漢字格。
   - **TTC 合集說明**：`.ttc` 可直接上傳，瀏覽器取用合集內預設字重；如需其他字重請先拆成單一 `.ttf`。
7. **匯出**：原圖 1:1 保留置中放入直式 A4，只疊加虛線，其他不變。
   - 「匯出直式 A4 PDF（全部頁）」→ 列印用。
   - 「匯出本頁/全部 PNG」→ 傳 Line / 貼學習單用。
