習寫簿虛線描寫工具

上傳 PDF / 截圖 → 自動標出空白格（亮光區）→ 點選要描寫的格 → 輸字 → 微調 → 匯出直式 A4 PDF / 圖片（原圖只加虛線，不做其他變更） 直式 A4 輸出

1. 上傳作業簿內頁

支援：多檔、PDF 多頁自動拆頁、截圖。每一頁會變成下方一個分頁，可逐頁編輯。
也可以直接把檔案拖進視窗放開上傳（PDF / 圖片）。
輸出時自動以直式 A4 置中套版。

2. 字體庫

「內建漢字 / 注音虛線字體」槽位永遠保留在庫內（請自行上傳有授權的字型檔使用）。你可上傳自備字體（.ttf / .otf / .woff2 / .ttc）隨時切換，字體檔可以直接拖進視窗上傳。
上傳時檔名含「注音」會自動歸到注音格字體，其餘歸到漢字格字體，之後都可在下拉選單改。
推薦字型（請自行準備有授權的檔案再上傳）：漢字格用文鼎標楷虛線國字，注音格用文鼎虛線注音。
尚未上傳
靈敏度 5 ｜版式 ｜以「田字格」為單位。切換版式後請「清除本頁格子」再重掃。
操作：點擊田字格＝選取/取消（亮光黃色＝空白格，會產生虛線，一格＝四小方格組成的整個田字格；灰色＝有字範例格，僅框出不預選，需要也可點選加入）。漢字大格 / 右側窄注音格 / 純注音格（小一）會依寬高比自動分類，分類錯可下拉更正。右側面板可填字、微調位置大小、調顏色粗細，即時預覽虛線底稿。

若你尚未載入虛線字體，建議選「虛線描邊模擬」，工具會用虛線筆觸畫出字形，仍可交作業。若已載入附件虛線字體，選「填色」效果最像印刷描紅本。

5. 匯出（原圖＋虛線，不動其他）

匯出時：原上傳畫面 1:1 保留、置中放入直式 A4，其餘留白，只疊加你選取格的虛線字。

手動補格
